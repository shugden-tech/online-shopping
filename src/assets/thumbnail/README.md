# Home banner pictures

Every image in this folder (`.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`) becomes one slide of the home page
banner, in file-name order. Name them `01-…`, `02-…` to set the order. All pictures should have the same
proportions; the banner takes the proportions of the first one (about 2.75 : 1, e.g. 2640 × 960, fits best).
The file name, without the number, is used as the picture's alt text.

When the folder has no pictures, the home page shows the illustrated slides instead.
